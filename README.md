# Diksha Morwal — Portfolio Website

Personal portfolio website built with **HTML5**, **Tailwind CSS CDN**, and **Vanilla JavaScript**.

## Features

- Multi-page portfolio (Home, About, Skills, Experience, Blog, Contact, Resume)
- Responsive design (desktop, tablet, mobile)
- Sticky navbar with hamburger menu
- Smooth scroll animations
- Blog search functionality
- Contact form
- Resume preview
- SEO optimized

## Tech Stack

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter)

## Deploy

| Platform | Instructions |
|----------|-------------|
| **GitHub Pages** | Push repo, enable Pages from main branch root |
| **Netlify** | Drag `portfolio/` folder or connect Git repo |
| **Vercel** | Import project, output dir set to `portfolio/` |
| **Cloudflare Pages** | Connect Git repo or upload folder |

## Run Locally

Open any `.html` file directly in browser:

```
open index.html
```

No build tools or npm required.
